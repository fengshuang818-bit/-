# 喀什 · 帕米尔旅行指南

一个纯 HTML/CSS/JS 的手机优先旅行攻略页面，无需构建工具。

## GitHub Pages

1. 新建 GitHub repository，例如 `kashi-pamir-guide`
2. 上传 `index.html` 与 `.github/workflows/deploy.yml`
3. Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**
4. 推送到 `main` 后，GitHub Actions 会自动部署。

GitHub Pages 官方文档：
https://docs.github.com/en/pages/getting-started-with-github-pages
